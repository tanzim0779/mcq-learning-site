# GyanPath MCQ Practice Exam

A simple mobile-friendly MCQ exam website containing only these three questions:
1. Who is the creator of the website?
2. What is the dream of Tanzim?
3. Will Tanzim be successful in his life?

## Files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — questions, timer, scoring, correct answers, and restart

## Run
Open `index.html` in a browser, or upload all three website files to your GitHub Pages repository.

## Important
This is a static practice site. Answers are stored in the browser-side `script.js`; it does not include a secure admin panel or shared database. To edit questions, update `quizData` in `script.js`.


## Calculator
This version adds a basic calculator section (addition, subtraction, multiplication, division, percentage, sign, decimal, clear, backspace). It works in the browser without a database.
