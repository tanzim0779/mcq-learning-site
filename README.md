# EXAM — TANZIM'S FIRST PROJECT

Black-themed, responsive HSC MCQ practice portal with 20 sample questions: 5 each from Physics, Chemistry, Mathematics, and English.

## Files
- `index.html`: structure and screens
- `style.css`: black theme and responsive layout
- `questions.js`: questions, options, correct answers, explanations
- `script.js`: 20-minute timer, navigation, scoring, review, restart

## Publish on GitHub Pages
Upload all four files to the **same root folder** in your repository. Then open **Settings → Pages**, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, and Save. Wait a few minutes and open the published link.

## Note
These are original practice questions intended to be broadly HSC-level. Check them against your specific board syllabus before formal use. This is a front-end demo; it does not store results online or provide secure accounts.
